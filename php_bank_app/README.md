# Капитал-Стандарт — PHP + MySQL демонстрационный банк

Русскоязычная демонстрационная банковская система с клиентским кабинетом и отдельной панелью банкира. Приложение рассчитано на PHP 8.1+ и MySQL 8.0+/MariaDB с InnoDB. Реальные платежные шлюзы и банковские API не подключены; суммы — внутренние демонстрационные единицы RUB.

## Возможности

### Клиент
- Регистрация, вход, выход и отдельный личный кабинет.
- Несколько текущих счетов и накопительные счета.
- Просмотр балансов и истории переводов/операций.
- Переводы между активными счетами системы по номеру счёта.
- Оплата счетов и штрафов, выставленных сотрудником банка.
- Повторяющиеся переводы: ежедневно, еженедельно, ежемесячно.
- Автооплата неоплаченных счетов по расписанию.
- Приостановка и возобновление автоматических правил.

### История и диаграмма
- История операций с открываемой столбчатой диаграммой поступлений и списаний за последние 12 месяцев.
- Поддерживается переключение между светлой и тёмной темой; выбор сохраняется в браузере.
- Переводы между своими счетами не считаются доходом/расходом в диаграмме, чтобы не задваивать суммы.

### Накопительный счёт
- Это отдельный баланс для накоплений, который можно пополнять переводом с текущего счёта.
- По умолчанию начисляется 5% годовых, проценты зачисляются раз в календарный месяц отдельной операцией в истории. Ставка задаётся параметром `SAVINGS_ANNUAL_RATE_PERCENT` или ключом `savings_annual_rate_percent` в `config/config.php`.
- Проценты рассчитываются на остаток счёта при первом запуске планировщика в соответствующем месяце; уникальная запись начисления не позволяет начислить проценты повторно за тот же месяц. Деньги не блокируются и могут переводиться обратно или использоваться для платежей.

### Банкир
- Отдельный интерфейс с обзором системы.
- Поиск клиентов, список владельцев счетов и балансы.
- Блокировка/разблокировка клиентов и отдельных счетов.
- Разовые зарплаты, пополнения и списания.
- Запланированные или повторяющиеся зарплаты/пополнения/списания.
- Выставление счетов, штрафов и коммунальных платежей; отмена неоплаченных требований.
- Журнал аудита административных действий.

## Установка на XAMPP (Windows)

1. Установите PHP 8.1+ и MySQL/MariaDB. Включите расширения `pdo_mysql` и `mbstring`.
2. Запустите Apache и MySQL в XAMPP.
3. Импортируйте `database/schema.sql` через phpMyAdmin. Скрипт создаёт базу `cci_bank`. Если база от предыдущей версии уже существует, выполните один раз `database/migrations/20261009_savings_interest.sql`.
4. Скопируйте папку проекта, например в `C:\xampp\htdocs\cci-bank`. Рекомендуемый вариант — указать `DocumentRoot` Apache на папку `public`. Для локального тестирования можно открыть `http://localhost/cci-bank/public/`; служебные папки закрыты через `.htaccess`, но для реального размещения всё равно используйте `public` как корень сайта.
5. Настройте параметры БД переменными окружения `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS`. Значения по умолчанию: `127.0.0.1:3306`, база `cci_bank`, пользователь `root`, пустой пароль. Ставка накопительного счёта по умолчанию — 5% годовых. Файл `.env.example` — справочный шаблон, он автоматически не загружается; для другой конфигурации задайте переменные окружения перед запуском Apache/PHP или измените значения в `config/config.php`.
6. Создайте учётную запись банкира из командной строки в корневой папке проекта:

   ```bash
   php bin/create_banker.php
   ```

   Скрипт запросит email, имя, фамилию и пароль. Регистрация на сайте всегда создаёт обычного клиента; получить права банкира через пользовательскую форму нельзя.
7. Откройте сайт. Клиент может зарегистрироваться через «Открыть счёт», а сотрудник банка входит через обычную форму входа и попадает в отдельную панель.

Для быстрого локального просмотра (при настроенной БД) можно выполнить из каталога проекта `php -S 127.0.0.1:8000 -t public`, затем открыть `http://127.0.0.1:8000`. Не используйте встроенный сервер PHP для публичного размещения.

## Автоматические операции

Планировщик не запускается сам по себе: его необходимо вызвать планировщиком операционной системы. Команда (она также начисляет проценты по накопительным счетам):

```bash
php /path/to/cci-bank/bin/cron.php
```

Запускайте каждые 1–5 минут. В Windows можно использовать «Планировщик заданий», указав `php.exe` как программу, а полный путь к `bin/cron.php` — как аргумент. У команды должен быть доступ к той же конфигурации БД, что и у веб-приложения.

## Основные меры безопасности

- PDO prepared statements, `password_hash`/`password_verify`, токены CSRF, экранирование HTML и cookie с `HttpOnly`/`SameSite`.
- Смена идентификатора сессии после входа, ограничение попыток входа в рамках сессии.
- Денежные значения хранятся в целых минимальных единицах (öre), а не во float.
- Переводы блокируют строки счетов и выполняются в транзакции БД; если проверка не проходит, изменения откатываются.
- Отдельная роль `banker`, созданная только из CLI-скрипта.
- Конфигурацию и служебные каталоги нельзя открывать через веб при Apache; рекомендуется публиковать именно каталог `public`.

## Важно перед использованием вне локальной среды

Это учебный/ролевой проект, а не программное обеспечение для настоящего банка. Перед размещением в интернете необходимы независимый аудит безопасности, HTTPS, отдельный пользователь БД с минимальными правами, системное ограничение частоты запросов, восстановление доступа, многофакторная аутентификация, резервное копирование, защита от мошенничества и юридическая/регуляторная проверка. Не используйте для настоящих денег, персональных банковских данных или производственных клиентов без такой подготовки.
